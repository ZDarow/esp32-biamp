# Подключение PCM5102A к ESP32 BiAmp

## Обзор

PCM5102A — стерео DAC от Texas Instruments с I²S-интерфейсом. Подключается
параллельно к выходу Master ESP32, не нарушая работу сниффера ESP32-S3.

## Распиновка PCM5102A

| Пин | Назначение | Подключение |
|---|---|---|
| 1 | CPVDD | 3.3V |
| 2 | VNEG | CAPP ↔ CAPM (10 µF) |
| 3 | CAPP | 10 µF → VNEG |
| 4 | CAPM | 10 µF → CAPP |
| 5 | AVDD | 3.3V |
| 6 | DGND | GND |
| 7 | BCK | I²S бит-такт |
| 8 | DIN | I²S данные |
| 9 | LRCK | I²S слово-такт |
| 10 | DVDD | 3.3V или 1.8V |
| 11 | SCL | Системный такт (GND для внутреннего PLL) |
| 12 | FMT | GND = I²S-формат |
| 13 | XSMT | 3.3V = unmute |
| 14 | DMP | DEMP = GND (де-эмфазис выкл) |
| 15 | FLT | FLT = GND (нормальная задержка) |
| 16 | LDOO | Не подключён |

## Минимальное подключение (один DAC, стерео)

```
PCM5102A    ESP32 Master (WROOM-32)
────────    ──────────────────────
DIN   (8) ← GPIO2   I²S0 DOUT (Z1 DATA)
BCK   (7) ← GPIO4   I²S0 BCLK (Z1 BCLK)
LRCK  (9) ← GPIO15  I²S0 LRCK (Z1 LRCK)
DVDD (10) ← 3.3V
AVDD  (5) ← 3.3V
CPVDD (1) ← 3.3V
DGND  (6) ← GND
GND   ────← GND
FMT  (12) ← GND (I²S-формат)
XSMT (13) ← 3.3V (unmute)
SCL  (11) ← GND (внутренний PLL)
```

## Параллельное подключение со сниффером

I²S-шина поддерживает несколько ведомых устройств. DAC подключается
**параллельно** со сниффером ESP32-S3 — в разрыв линий **не** вставляется.

```
Master GPIO2 ───┬──▶ S3 GPIO17 (CAP_Z1_DATA)
                └──▶ PCM5102A DIN (8)

Master GPIO4 ───┬──▶ S3 GPIO16 (CAP_Z1_BCK)
                └──▶ PCM5102A BCK (7)

Master GPIO15 ──┬──▶ S3 GPIO18 (CAP_Z1_LRCK)
                └──▶ PCM5102A LRCK (9)

GND ────────────┬──▶ S3 GND
                └──▶ PCM5102A GND (6)
```

## Два DAC (полная копия 4 каналов)

Для полной копии всех 4 каналов Master нужны два PCM5102A:

```
Первый DAC (Z1, левый/правый):
  DIN  ← GPIO2   (Z1 DATA)
  BCK  ← GPIO4   (Z1 BCLK)
  LRCK ← GPIO15  (Z1 LRCK)

Второй DAC (Z2, левый/правый):
  DIN  ← GPIO26  (Z2 DATA)
  BCK  ← GPIO25  (Z2 BCLK)
  LRCK ← GPIO27  (Z2 LRCK)
```

## Проверка работоспособности

1. Подключите DAC параллельно снифферу согласно схеме выше.
2. Запустите тестовый сценарий `tone-low` или `tone-high`:
   ```powershell
    py -3.14 firmware/tools/capture-analyze.py --sniffer COM13 --master COM8 --scenario tone-low
   ```
3. На слух проверьте наличие тона на выходе DAC.
4. Убедитесь, что сниффер продолжает захватывать данные без ошибок.

## Важные замечания

- **Общая земля обязательна.** Без неё уровны 3.3 В не определены.
- **Не поднимать громкость выше 6%** при включённом тест-сигнале.
- **XSMT должен быть высоким** (3.3V) — иначе DAC замьютирован.
- **FMT = GND** — выбирает I²S-формат (не left-justified).
- **SCL = GND** — включает внутренний PLL DAC, внешний такт не нужен.
- **DEMP = GND** — де-эмфазис выключен (для 44.1/48 кГц).
- **FLT = GND** — нормальная задержка фильтра.

## Совместимость с существующим подключением

| Устройство | Порт | Питание | Интерфейс |
|---|---|---|---|
| ESP32 Master | COM8 | USB | SPP 115200 |
| ESP32-S3 сниффер | COM13 | USB | Нативный USB |
| PCM5102A DAC | — | 3.3V | I²S slave |

Сниффер продолжает работать без изменений прошивки. DAC — пассивный
слушатель шины, не требует прошивки вообще.
