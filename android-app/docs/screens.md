# Текстовое описание экранов приложения «Кроссовер» (спека для воспроизведения UI)

## Общие элементы (идентичны на всех трёх скриншотах)

**Системный статус-бар (верх):**
- Чёрная полоса, белый текст и иконки. Слева: время «14:21», иконка-щит (индикатор стороннего приложения). Справа: квадратная иконка, Bluetooth, надпись «LTE», индикатор мобильной связи со значком «!», заряд батареи «63–64 %».
- Системный элемент, не часть UI приложения (при воспроизведении учитывать только как inset).

**Шапка приложения (toolbar):**
- Чёрная полоса во всю ширину под статус-баром, высота ≈ 64–70 dp.
- Слева: белый шеврон «<» (кнопка «Назад»), сразу за ним заголовок раздела «Кроссовер» (белый, ≈ 22 sp, обычный регистр).
- По центру шапки: синяя иконка динамика с двумя звуковыми волнами (акцентный голубой, ≈ #00A0E0), выровнена по горизонтали по центру экрана.

**Фон экрана:**
- Тёмные абстрактные обои: почти чёрная база с широкими диагональными (≈ 45°, снизу-слева вверх-вправо) синими полосами-волнами со свечением (оттенки от #0A1A2F до #4A86C8).
- Весь контент под шапкой лежит прямо на фоне — без карточек, панелей и подложек.

**График АЧХ (верх контентной области):**
- Занимает ≈ 90 % ширины экрана и ≈ 26–27 % высоты; боковые отступы ≈ 5 %.
- Область построения: прямоугольник с тонкой серой рамкой; фон полупрозрачный (обои просвечивают).
- Над правым верхним углом прямоугольника: мелкая белая подпись осей «дБ/Гц».
- Ось Y (слева за рамкой): белые метки 6, 0, -6, -12, -18, -24 (дБ), выровнены по горизонтальным линиям сетки.
- Ось X (под рамкой): белые метки 10, 20, 50, 100, 200, 500, 1k, 2k, 5k, 10k, 20k (Гц), шкала логарифмическая.
- Сетка: тонкие серые линии — горизонтальные через каждые 6 дБ, вертикальные по логарифмическим делениям декад.
- Кривая АЧХ: сплошная линия акцентного синего (≈ #00A0E0), толщина ≈ 2 dp, без заливки, без маркеров точек.

**Заголовок полосы (под графиком):**
- Крупный белый центрированный текст (≈ 28–32 sp) — название полосы АС (разное на каждом экране).

**Строки параметров (степперы), ниже заголовка:**
- Каждая строка — горизонтальный блок: [метка параметра] [шеврон «<»] [поле значения] [шеврон «>»].
- Метка: белая, ВЕРХНИМ регистром, ≈ 18–20 sp, выровнена по правому краю левой колонки (граница колонки ≈ 36 % ширины экрана).
- Шевроны «<» и «>»: акцентный синий, жирные (штрих ≈ 3 dp), высота ≈ 24 dp; работают как кнопки уменьшения/увеличения значения.
- Поле значения: серый полупрозрачный прямоугольник (≈ #808080, прозрачность ≈ 70 %), ширина ≈ 35 % экрана, высота ≈ 48–56 dp, углы прямые или минимально скруглены; текст значения белый, по центру, ≈ 18–20 sp.
- Строки расположены равномерно по вертикали (шаг ≈ 70–75 dp), без разделителей и рамок вокруг строк.

**Системная навигация (низ):**
- Белая горизонтальная «пилюля» жестовой навигации Android по центру внизу. Системный элемент.

## Экран 1 — полоса «Сабвуфер»

- **Кривая на графике:** фильтр низких частот (ФНЧ). Полка 0 дБ от 10 Гц до ≈ 40–50 Гц; плавный крутой спад начиная с ≈ 50 Гц; пересечение -6 дБ на ≈ 100 Гц; выход за нижнюю границу графика (-24 дБ) на ≈ 190–200 Гц; правее 200 Гц кривая не отображается.
- **Заголовок полосы:** «Сабвуфер».
- **Параметры (4 строки, сверху вниз):**
  1. ФНЧ ЧАСТОТА — значение «80Гц»
  2. ФНЧ СПАД — значение «-18»
  3. ФНЧ УРОВЕНЬ — значение «0»
  4. ФАЗА — значение «0 Градусов»

## Экран 2 — полоса «СЧ-Динамики»

- **Кривая на графике:** полосовой фильтр (ФВЧ + ФНЧ). Вход слева снизу (-24 дБ на ≈ 18–20 Гц); крутой подъём: -12 дБ на ≈ 35 Гц, -6 дБ на ≈ 55–60 Гц; плоская полка ≈ 0 дБ в диапазоне ≈ 150 Гц – 2 кГц; плавный спад справа: -6 дБ на ≈ 8 кГц, окончание на ≈ -13 дБ на 20 кГц.
- **Заголовок полосы:** «СЧ-Динамики».
- **Параметры (6 строк, сверху вниз):**
  1. ФВЧ ЧАСТОТА — значение «80Гц»
  2. ФВЧ СПАД — значение «-12»
  3. ФНЧ ЧАСТОТА — значение «4kГц»
  4. ФНЧ СПАД — значение «-6»
  5. УРОВЕНЬ — значение «0»
  6. ФАЗА — значение «0 Градусов»

## Экран 3 — полоса «ВЧ-Динамики»

- **Кривая на графике:** фильтр высоких частот (ФВЧ). Ниже -24 дБ до ≈ 1,5 кГц (вход в область графика снизу на ≈ 1,6 кГц); крутой подъём: -12 дБ на ≈ 2,8–3 кГц, -6 дБ на ≈ 4 кГц; выход на полку ≈ -2 дБ (чуть ниже линии 0 дБ) с ≈ 8–10 кГц до 20 кГц.
- **Заголовок полосы:** «ВЧ-Динамики».
- **Параметры (4 строки, сверху вниз):**
  1. ФВЧ ЧАСТОТА — значение «5kГц»
  2. ФВЧ СПАД — значение «-12»
  3. ФВЧ УРОВЕНЬ — значение «-2»
  4. ФАЗА — значение «0 Градусов»

## Различия экранов и логика (для агента кодирования)

- Все три экрана одного типа; различаются только именем полосы, формой кривой и составом строк параметров.
- Состав строк зависит от типа фильтров полосы:
  - только ФНЧ (сабвуфер): ФНЧ ЧАСТОТА, ФНЧ СПАД, ФНЧ УРОВЕНЬ, ФАЗА;
  - ФВЧ + ФНЧ (СЧ): ФВЧ ЧАСТОТА, ФВЧ СПАД, ФНЧ ЧАСТОТА, ФНЧ СПАД, УРОВЕНЬ, ФАЗА;
  - только ФВЧ (ВЧ): ФВЧ ЧАСТОТА, ФВЧ СПАД, ФВЧ УРОВЕНЬ, ФАЗА.
- Кривая графика — визуализация текущих значений параметров (частота среза, крутизна спада, уровень): график пересчитывается при изменении значений степперами.
- Форматы значений: частота — «80Гц», «4kГц», «5kГц»; крутизна — «-18», «-12», «-6» (дБ/окт); уровень — «0», «-2» (дБ); фаза — «0 Градусов».
