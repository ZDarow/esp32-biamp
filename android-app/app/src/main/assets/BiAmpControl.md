## 1. Назначение и состав системы

BiAmp Control — комплект из прошивки и Android-приложения для управления
Bluetooth-колонкой с активным би-ампингом (2 колонки × НЧ+ВЧ = 4 канала).

**Аппаратная часть:**
- ESP32 (WROOM, без PSRAM), прошивка `bi-amp v15`;
- 2 × ЦАП PCM5102A (стерео каждый): ЦАП L = НЧ-Л + ВЧ-Л, ЦАП R = НЧ-П + ВЧ-П;
- OLED 128×64 (I2C, addr 0x3C);
- энкодер с кнопкой (CLK=16, DT=17, SW=5).

**Каналы связи:**
| Канал | Назначение |
|---|---|
| BT A2DP | аудиопоток с телефона (музыка) |
| BT SPP (RFCOMM) | команды управления из приложения |
| USB Serial 115200 | дублирующий канал команд и отладка |

**Программная часть (приложение):**
- `bt/SppManager.kt` — RFCOMM-клиент, автореконнект (5 попыток: 2/4/8/15/30 с);
- `bt/CommandSender.kt` — очередь команд, троттлинг ползунков 150 мс;
- `bt/Protocol.kt` — `DeviceState` + терпимый парсер ответа `status`;
- `BiAmpViewModel.kt` — состояние, команды, автоопрос `status` каждые 3 с;
- вкладки Compose: «Громкость», «DSP», «Сервис».

## 2. Подключение и индикаторы

| Элемент шапки | Значение |
|---|---|
| Бейдж **ON** (зелёный) | SPP-сеанс активен, команды ходят |
| Бейдж **…** / **RE** | подключение / автореконнект |
| Бейдж **OFF** (красный) | соединения нет |
| **Подкл.** | список сопряжённых BT-устройств |
| **Откл.** | разрыв SPP-сеанса |

**Первый запуск:**
1. Сопряги телефон с устройством `ESP32 BiAmp Speaker` в настройках BT.
2. В приложении: «Подкл.» → выбрать устройство.
3. Музыка подключается отдельно — как к обычной BT-колонке (A2DP).

## 3. Вкладка «Громкость»

| Элемент | Диапазон | Команда | Назначение |
|---|---|---|---|
| Общая | 0–100 % | `vol:N` | громкость обеих зон |
| Левая (L) | 0–100 % | `v0:N` | громкость левой колонки |
| Правая (R) | 0–100 % | `v1:N` | громкость правой колонки |
| Баланс | −10…+10 | `bal:N` | смещение баланса (− влево) |
| Mute Л / Mute П | — | `mute:0` / `mute:1` | переключить беззвучие зоны |
| ⏮ ▶ ⏸ ⏭ | — | `prev/play/pause/next` | управление плеером телефона (AVRCP) |
| Flat/Voice/Night/Party | — | `preset:0..3` | пресеты DSP (§7) |

> Ползунки шлют команды с троттлингом 150 мс; последнее значение доводится всегда.

## 4. Вкладка «DSP»

| Элемент | Диапазон | Команда | Назначение |
|---|---|---|---|
| Fc | 200–1000 Гц, шаг 50 | `fc:N` | точка раздела кроссовера НЧ/ВЧ |
| Сабсоник HPF | вкл/выкл | `sub:1/0` | защита НЧ от инфранизких |
| HPF | 20–80 Гц, шаг 5 | `hp:N` | частота сабсоника |
| НЧ (LF) | −6…+3 дБ, шаг 0,5 | `tlf:N` | трим ветки вуферов |
| ВЧ (HF) | −6…+3 дБ, шаг 0,5 | `thf:N` | трим ветки твитеров |
| Low 120 Hz | −12…+12 дБ | `eql:N` | полка НЧ эквалайзера |
| Mid 1 kHz | −12…+12 дБ | `eqm:N` | пик середины |
| High 6 kHz | −12…+12 дБ | `eqh:N` | полка ВЧ |
| Кнопка «0» у полосы | — | `eqX:0` | сброс одной полосы EQ |
| Чипы НЧ-Л/ВЧ-Л/НЧ-П/ВЧ-П | — | `inv:0..3` | инверсия фазы канала |
| Сброс инверсий | — | `inv:off` | все каналы в прямую фазу |

> Смена Fc/EQ/тримов применяется **без щелчков**: коэффициенты подменяются
> атомарно в аудио-потоке (флаг `filter_dirty`).

## 5. Вкладка «Сервис»

### 5.1. Тест динамиков
Тон задаётся полем «Гц» + кнопка **TF** (по умолчанию 440 Гц, команда `tf:N`).

| Кнопка | Команда | Что играет |
|---|---|---|
| Все | `test:all` | тон во всех 4 динамиках |
| НЧ | `test:woof` | оба вуфера |
| ВЧ | `test:tweet` | оба твитера |
| ch1…ch4 | `test:1..4` | ch1=НЧ-Л, ch2=ВЧ-Л, ch3=НЧ-П, ch4=ВЧ-П |
| Ант | `test:anti` | лево в фазе, право в противофазе (проверка полярности) |
| Сви | `test:sweep` | свип 20 Гц → 20 кГц, цикл 10 с |
| СТО | `test:off` | остановить тест |

Дополнительно (только команды): `test:l` / `test:r` — тон целиком в левой/правой колонке.

### 5.2. Диагностика
Карточка обновляется автоматически (опрос `status` каждые 3 с):
- `V0/V1/bal` — громкости и баланс;
- `Fc/hp/sub` — кроссовер и сабсоник;
- `TLF/THF` — тримы; `EQ` — эквалайзер; `INV` — инверсии (4 цифры);
- `BT: ON|OFF` — телефон по аудио; `SPP: ON|OFF` — сеанс управления;
- `Test: N` — активный тест-режим.

Кнопки: **Stats** (`stats`: кадры, underrun, клипы), **Heap** (`heap`: свободная память),
**Meta** — зарезервировано (в v15 команда `meta` не обрабатывается).

### 5.3. Опасные действия (диалог подтверждения)
- **Сохранить (save)** — немедленная запись параметров в NVS;
- **Перезагрузка (reboot)** — рестарт ESP32;
- **Заводской сброс (factory)** — очистка NVS и рестарт.

## 6. Управление на корпусе устройства

| Орган | Действие |
|---|---|
| Поворот энкодера | общая громкость обеих зон (~2 % на детент) |
| 1 клик кнопки | mute/unmute обеих зон |
| Удержание ≥ 1 с | сброс громкости в 10 % (клик после удержания не считается) |

**OLED:** строка 1 — `BT ON/--` + маркер `SPP`; строка 2 — `PLAY/PAUSE/MUTED`;
строки 3–4 — громкости `L %` и `R %`.

## 8. Протокол команд

Текстовые команды, терминатор `\n` (принимается и `\r`), макс. 63 символа.
Источники: приложение (SPP) и USB Serial — оба одновременно.

| Команда | Аргумент | Действие |
|---|---|---|
| `vol:N` | 0–100 | общая громкость |
| `v0:N` / `v1:N` | 0–100 | громкость зоны |
| `bal:N` | −10…10 | баланс |
| `mute:N` | 0/1 | переключить mute зоны |
| `fc:N` | 200–1000 | частота кроссовера |
| `hp:N` | 20–80 | частота сабсоника |
| `sub:N` | 0/1 | сабсоник вкл/выкл |
| `tlf:N` / `thf:N` | −6…3 | тримы веток, дБ |
| `eql:N` / `eqm:N` / `eqh:N` | −12…12 | полосы EQ, дБ |
| `inv:N` / `inv:off` | 0–3 | инверсия фазы канала / сброс |
| `preset:N` | 0–3 | применить пресет |
| `play` `pause` `next` `prev` | — | AVRCP-транспорт |
| `test:<имя>` | all/l/r/woof/tweet/1-4/anti/sweep/off | тест-сигналы |
| `tf:N` | 20–20000 | частота тест-тона |
| `status` | — | 7 строк состояния |
| `stats` | — | счётчики кадров/underrun/клипов |
| `heap` | — | свободная память |
| `save` / `reboot` / `factory` | — | сервисные действия |
| `help` | — | справка |

Невалидные аргументы (`nan`, `inf`, вне диапазона, пустые) **игнорируются**.

## 9. Сохранение настроек (NVS)

Сохраняются: громкости, mute, Fc, hp, sub, тримы, EQ, баланс, инверсии.
- Автосохранение — через 2 с после последнего изменения;
- `save` — принудительно; `factory` — полный сброс;
- namespace: `biampv12` (совместим с предыдущими версиями прошивки).

---

## 10. Встроенные защиты (v15)

- Отсев NaN/Inf и выходных значений во всех числовых командах (`safeCmdVal`);
- безщёлчковое применение фильтров (`filter_dirty`) и плавный набор громкости (ramp);
- троттлинг ползунков 150 мс с вытеснением устаревших значений;
- автореконнект SPP: 5 попыток (2/4/8/15/30 с);
- софт-лимитер 0,8 со счётчиками клипов (`stats`);
- авто-ресемплер 48 → 44,1 кГц;
- дебаунс: кнопка 30 мс; энкодер — опрос 1 кГц, окно стабильности 3 мс;
- игнор сверхдлинных строк в командном потоке;
- атомарные флаги (`std::atomic`) для межзадачного состояния.

## 11. Неисправности и устранение

| Симптом | Проверка / действие |
|---|---|
| Бейдж OFF/RE | BT включён? устройство сопряжено? перезагрузить колонку |
| Нет звука при ON | `BT:` в диагностике = ON? подключи музыку; проверь mute и громкость |
| Ползунки не влияют | `SPP: ON`? если OFF — переподключись |
| Тихо после тестов | выключи тест: СТО (`test:off`) |
| Бас «пустой» | прогони `test:anti`; при пропадании баса инвертируй канал (`inv:0..3`) |
| Настройки слетели | был выполнен `factory`; восстановление только из NVS |
| Кнопка Meta молчит | команда не реализована в v15 (см. §5.2) |

## 12. Спецификация

- Аудио: 44,1 кГц / 16 бит, стерео на каждый ЦАП;
  каналы: ch0=НЧ-Л, ch1=ВЧ-Л, ch2=НЧ-П, ch3=ВЧ-П;
- пины: ЦАП L BCK=4 LCK=15 DIN=2; ЦАП R BCK=26 LCK=25 DIN=27; OLED SDA=21 SCL=22;
  энкодер CLK=16 DT=17 SW=5;
- BT-имя: `ESP32 BiAmp Speaker`; SPP UUID: `00001101-0000-1000-8000-00805F9B34FB`;
- память после старта A2DP+SPP: ~64 КБ свободно;
- приложение: офлайн, разрешения только Bluetooth; minSdk 26, targetSdk 35.

## 13. Сборка (памятка разработчику)

**Прошивка (Arduino IDE, Windows):**
- Partition Scheme: `Huge APP (3MB No OTA/1MB SPIFFS)`;
- библиотеки: audio-tools 1.2.5, ESP32-A2DP 1.8.11, Adafruit GFX/SSD1306;
- примечание: `a2dp_sink.start()` возвращает `void` (не присваивать результат).

**Приложение (VSCode + Gradle, Windows):**
```powershell
.\gradlew.bat assembleDebug
adb install -r app\build\outputs\apk\debug\app-debug.apk
```
- JDK 17, Android SDK cmdline-tools, `ANDROID_HOME` в PATH;
- зависимости: только AndroidX / Compose BOM / Coroutines / material-icons-extended.
